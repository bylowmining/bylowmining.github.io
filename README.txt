BYLOW MINING — WEBSITE INFORMATION FOR IT AND TEACHERS
Version 1.5

HOW THIS WEBSITE WORKS

This is a static HTML/CSS/JavaScript site. No student accounts, analytics, advertisements, cookies, third-party scripts, APIs, or server-side database are used. Math questions are generated in the browser, including division with remainders and fractions. Progress is saved using browser localStorage when permitted.

IMPORTANT

There is no automatic connection to the teacher dashboard, no access to its stored classroom data, and no automatic Coin payouts. Student reports are self-generated and are not tamper-proof. The teacher reviews written calculations and approves rewards. No work shown means no Coins approved. Once either daily limit is reached (5 Coins or 3 wrong answers), practice does not earn Coins or advance levels. The browser clock and locally stored reports are not tamper-proof.

DEPLOYMENT

Upload index.html and bylow-coin.png to the root of the student GitHub Pages repository. This README is documentation and may be kept separately or included in the repository. The site itself does not need README.txt to operate.

DATA STORAGE AND LIMITATIONS

Progress is saved locally on the current browser/device and does not automatically sync to other devices. Clearing browser storage can erase progress. Midnight resets use the device's local clock. A student may continue practice after the earning limit. Student reports should be checked against written work before Coins are awarded.

DEMONSTRATION MODE

The normal student interface does not advertise a DEMO button. Demonstration access is intended for teacher/IT review only, but a hidden URL is not secure authentication. See the private IT package for any demonstration-specific setup.
